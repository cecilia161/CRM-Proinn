Importar contactos desde Excel

Archivo: —

Se detectaron 0 fila(s).

Si el Excel trae una columna con el nombre de la vendedora (ej. "Vendedor"), cada contacto nuevo se asigna automáticamente a quien coincida en el equipo; si no se reconoce el nombre, se usa el representante técnico elegido arriba. Solo se omiten las filas totalmente vacías. Las que traigan datos pero les falte Nombre, Empresa, Tipo de negocio, Celular, Correo, Región o Comuna igual se importan — al final te muestro el detalle para que las completes después. Si el Excel trae columnas de visita (Fecha, Estado, Resultado) y de venta (Monto Vendido, Fecha Venta), también se registran como Visitas y Ventas de cada cliente. Si además trae "Monto Validado"/"Fecha Venta Validada" para alguna fila, esos datos mandan por sobre el Monto Vendido/Fecha Venta de esa fila — y si esa venta ya estaba registrada de una importación anterior sin validar, se actualiza con el dato validado en vez de crear una venta aparte. Si el cliente ya existe (mismo RUT o misma empresa), se actualiza en vez de crear uno repetido.

Importar ventas desde Excel

Archivo: —

Se detectaron 0 venta(s) (las filas de subtotal/total del reporte se excluyen automáticamente).

Contactos cargados para buscar coincidencias: 0 — parece muy bajo, espera unos segundos a que termine de cargar tu cartera antes de importar.

Solo se usa para las filas que NO traigan una columna "Fecha" propia con el día exacto — esas se registran el día 15 del mes correspondiente, como respaldo.

Se busca cada Cliente por nombre de Empresa/Razón social entre tus contactos ya cargados (tolera diferencias de mayúsculas, tildes y también de "Ltda./SpA./EIRL/SA" al final). Si hay más de un contacto con ese mismo nombre en representantes técnicos distintos, se usa la columna "Vendedora" del Excel para elegir el correcto — si sigue sin poder resolverse, esa fila no crea nada y queda en el reporte para que la revises a mano.

Ventas que parecen duplicadas

No se encontró ninguna venta que parezca registrada más de una vez. 👍

Se agrupan las Actividades de tipo "Venta" que comparten el mismo cliente y la misma fecha — lo típico cuando el mismo Excel se sube más de una vez. Si además coincide el monto, se dejan marcadas para eliminar todas menos la más antigua. Si el monto es distinto (⚠️, por ejemplo una venta vieja con el monto mal leído junto a su corrección), no se marca nada automático — revisa los montos y marca tú cuál eliminar.
